## 0. 한눈에 — 이 전략이 하려는 것
역추세는 **각 진입이 독립된 "게임"의 시작**이다. 게임이 진입가보다 더 빠지면(지고 있으면) 신호가
다시 뜨는데, 그때 **그 게임에 한 번 더 사서(추매) 평단을 낮추고, TP/SL을 새 평단 기준으로 다시 잡아**
그 게임의 승률을 끌어올린다. **새 게임을 여는 동작은 그대로 둔다(중첩 유지).**

결과 요약: **승률 +1~4%p 오른다(의도대로 됨).** 단 추매분만큼 자본을 더 투입하므로(≈1.8배)
수익·낙폭이 같이 커지는 **조건부 레버리지**다. 위험조정(수익/낙폭)은 거의 그대로. §4 수치 참조.

## 1. ⭐ "중첩(동시보유)"이 뭔지 — 오해 방지용 (반드시 먼저 읽기)

역추세 봇은 **한 심볼에 여러 포지션을 동시에** 들고 갈 수 있다. 이걸 중첩(overlapping)이라 한다.

- **게임 = 포지션 하나.** 신호가 뜰 때마다 새 게임(포지션)을 연다.
- **쿨다운**은 *새 게임을 여는 간격*만 제한한다. 예: 쿨다운 3h면, 직전에 연 게임으로부터 3h 지나야
  다음 게임을 연다. **이미 열린 게임이 닫히길 기다리지 않는다.** → 그래서 큰 하락이 며칠 이어지면
  3h 간격으로 게임이 여러 개 겹쳐서 열린다(동시보유 5~14개도 정상).
- 각 게임은 **자기만의 진입가·TP·SL**을 갖고 **독립적으로** 청산된다.

> ❗흔한 오해: "한 포지션 닫아야 다음 진입" → **틀림.** 그건 단일포지션 모델(별도 검증용)이다.
> 라이브·이 문서의 정본은 **중첩**이다. 빈도가 단일포지션의 3~5배(연 30+회/심볼)인 이유가 이것.

**추매는 이 중첩을 건드리지 않는다.** 새 게임은 평소대로 다 연다. 추매는 그 위에, *이미 열려있는
각 게임*에 다리를 하나 더 얹는 별도 동작이다.

## 2. 진입·청산 기본 규칙 (추매 없을 때 = 원본)
1분봉. win=10080(7일) 고정. z=(close−MA)/σ. **손절 우선**, fee 0.11% 왕복, **최대보유 14일**(미도달 종가청산).

| 방향 | 진입 신호 | 1차 TP | 1차 SL |
|---|---|---|---|
| 역추세 롱 | `z ≤ −K1` (급락) | `TP = MA − B·σ` (진입가 위) | `SL = 진입가 × (1 − pct)` |
| 역추세 숏 | `z ≥ +K1` (과열) | `TP = MA + B·σ` (진입가 아래) | `SL = 진입가 × (1 + pct)` |

`pct` = 진입가에서 TP까지의 거리 비율. 롱: `pct = TP/진입가 − 1`. 숏: `pct = 1 − TP/진입가`.
유효성: 롱은 `TP > 진입가`, 숏은 `TP < 진입가`여야 함(아니면 그 신호는 진입 스킵).

## 3. ⭐ 추매: TP/SL을 어떻게 바꾸는가 (정확 식 + 예시)

추매가 일어나면 **기존 TP/SL을 버리고 새 평단 기준으로 다시 계산**한다. 3단계:

**① 평단 갱신** (1:1 균등 사이징 — 추매도 같은 물량)
```
평단(avg) = (모든 진입가의 단순평균)          # 첫 추매면 avg = (P0 + P1) / 2
```

**② TP를 "추매하는 그 순간"의 밴드로 재앵커** (← 핵심. 진입 때 값이 아니라 현재 MA·σ 사용)
```
역추세 롱: TP = MA[추매시점] − B·σ[추매시점]      # 유효: TP > avg
역추세 숏: TP = MA[추매시점] + B·σ[추매시점]      # 유효: TP < avg
```
유효하지 않으면(롱인데 TP ≤ avg 등) **그 게임엔 이번 추매를 하지 않는다**(새 게임만 평소대로).

**③ SL = 새 평단 대칭**
```
pct = |TP − avg| / avg
롱: SL = avg × (1 − pct)
숏: SL = avg × (1 + pct)
```

추매 후 **두 다리가 새 TP/SL로 같이 청산**된다(원래 TP/SL은 폐기). 최대보유 14일은 **첫 진입 기준** 유지.

### 숫자 예시 (역추세 롱, B=1·σ=5 가정)
| | 1차 진입 | 추매 후 |
|---|---|---|
| 진입가 | P0 = 100 | P1 = 96 추가 → **평단 98** |
| 그 시점 MA | 110 | 107 (하락) |
| TP = MA−B·σ | 110−5 = **105** | 107−5 = **102** (가까워짐 ↓) |
| pct | 105/100−1 = 5% | 102/98−1 = 4.1% |
| SL | 100×(1−.05) = **95** | 98×(1−.041) = **94** |

→ **TP는 떨어진 MA 따라 가까워져(105→102) 얕은 바운스에도 익절**(승률↑). **SL은 낮아진 평단 기준으로
재설정**(95→94). 2차가 더 싸게(96) 들어와 같은 SL에 닿아도 두 다리 평균손실은 1차 단독보다 작을 수 있음.
숏은 부호만 미러(추매=더 높은 가격에 추가→평단↑, TP=MA+Bσ 위, SL 평단 위).

## 4. ⭐ 추매를 "언제" 하는가 — 구현 알고리즘 (정본 = `mode="ontop"`)

추매 트리거 = **새 게임을 여는 그 신호**(쿨다운 통과한 신호)와 동일. 한 신호가 두 가지를 동시에 한다:
(a) 새 게임을 연다, (b) *이미 열려있고·자기 쿨다운 지나고·아직 추매 안 한* 모든 게임에 추매를 얹는다.

```text
각 심볼마다 (K1, B, 쿨다운cd)로:
  cand = 신호 봉들  (롱: z ≤ −K1 / 숏: z ≥ +K1),  단 워밍업 WIN 이후
  last_entry = None
  games = []                                    # 열린·닫힌 게임 전체

  for ci in cand (시간순):
     if last_entry != None and ts[ci] − last_entry < cd:   # 쿨다운 게이트(새 게임 간격)
        continue
     price = close[ci]

     # (a) 추매 얹기 — 열린 모든 적격 게임에
     for g in games:
        if g.adds < MAX_ADDS                      # 추매 한도(현재 1)
           and g.side == 이 방향
           and g.entry_ts ≤ ts[ci] − cd           # 그 게임의 쿨다운도 지났을 것
           and g.exit_ts  > ts[ci]:                # 아직 안 닫힘(열려있음)
              avg' = mean(g.entry_prices + [price])
              TP', SL' = targets(MA[ci], σ[ci], avg', 방향, B)   # §3 ②③
              if 유효:
                 g.entry_prices.append(price); g.avg = avg'
                 g.TP, g.SL = TP', SL'; g.adds += 1
                 g.exit = 전진재청산(ci+1 .. 첫진입+14일, TP', SL', 손절우선)   # exit_ts 갱신

     # (b) 새 게임 열기 (중첩 — 평소대로)
     TP, SL = targets(MA[ci], σ[ci], price, 방향, B)
     if 유효:
        exit = 전진청산(ci+1 .. ci+14일, TP, SL, 손절우선)
        games.append( 새 게임{entry_ts, entry_prices=[price], avg=price, TP, SL, exit, adds=0} )
        last_entry = ts[ci]
```

핵심 포인트(구현 시 실수 주의):
- 쿨다운 게이트는 **새 게임 간격**만 본다. 추매는 그 통과한 신호에 *덤으로* 얹는다(별도 쿨다운 없음).
- 추매 후 **exit를 반드시 새 TP/SL로 다시 계산**한다. 최대보유는 **첫 진입+14일**(추매시점 아님).
- 추매 대상은 "그 게임의 진입+cd ≤ 현재 & 아직 열림 & 추매한도 남음". 보통 직전에 연 게임이 해당.
- 손익 = **다리별 방향수익률의 평균 − fee**. (1:1 균등이므로 단순평균)

> 변형 메모(아직 미확정): `MAX_ADDS`(추매 횟수 1/2/3…), 사이징(균등 vs 마틴게일), SL 방식(평단대칭 vs
> 원SL유지 vs ATR). 현재 정본은 **MAX_ADDS=1·균등·평단대칭SL**. 바꾸려면 위 targets/사이징만 교체.
