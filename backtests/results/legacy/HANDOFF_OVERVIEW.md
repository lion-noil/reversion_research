## 4. 결론 / 주의
- **권장 운용: USD 계좌 전부 2% / USDT 계좌 2% / 4전략 전부.** 둘 다 무청산, USD 2.1배·USDT 2.4배.
- **FX 5%는 비환율과 합치면 청산** → 한 USD 계좌면 2% 통일. (FX만 따로 계좌 쓸 거면 5% 가능.)
- **수익원 집중**: USD는 BTCUSD·ETHUSD 추세롱이 견인(+10%·+7%), USDT는 SOL·XRP·BTC 추세롱. 지수·FX는 분산·저변동 재료.
- **전부 in-sample.** OOS walk-forward 필수. Bybit·1분봉은 데이터 짧음(~3~6년) → 일봉 MT5(10년)보다 신뢰 낮음.
- **🔴 FX·금속은 스프레드·스왑 미반영** — 건당 엣지 작아 실비용에 취약. 라이브 전 비용 백테스트 필수.
- **MTM 낙폭은 보수적**(롱+숏 양다리 최악 동시가정), 실제론 덜 빠짐.
