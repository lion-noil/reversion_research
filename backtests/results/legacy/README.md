## ⚠️ 라이브 정합성 주의
- **현재 배포된 봇 채널은 v1 문서 기준**입니다: 일봉 FX 페이퍼(fxd, 커밋 06d77bd) = `HANDOFF_DAILY_FX.md`, 일봉 비환율 라이브(cryptod/mt5d, 2026-07-01) = `HANDOFF_DAILY_MT5.md`.
- 봇을 마스터 v2(창 재배정)로 올리기 전까지는 **라이브 파라미터의 원본이 이 legacy 문서들**이니 삭제 금지.
- 기준 확정(2026-07-09): **일봉 maxc≤15·보유15일·연≥10** (초기의 maxc≤10·보유30일 아님), 1분봉 maxc<15·보유14일.
