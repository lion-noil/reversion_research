## 2. 심볼 성향 (적용 가이드)

- **AUD·NZD(상품/리스크 통화) = 평균회귀형.** 역추세 롱·숏 둘 다 유효(특히 NZD 양방향, AUD는 3방향). S2 주력.
- **EURUSD = 추세롱만**(+0.78%), 역추세는 죽음(−0.11%). 잔잔한 메이저라 안 되돌리고 천천히 추세.
- **USDCHF = 추세숏 최강**(+1.04%) + 역추세숏. 안전자산 추세.
- **USDJPY = 역추세숏 + 추세숏** (USD강세/엔약세 국면).
- **GBPUSD = 역추세롱 + 추세롱**(둘 다 약~중).

## 3. ⚠️ 적용 전 반드시

1. **환율 기대값은 작다(+0.2~1.0%/건).** 지수·크립토(+1~3%)의 1/3~1/5. **포트폴리오 비중을 작게** 잡을 것. 기대 <+0.3% 픽(EURUSD 역추세롱·USDCAD/AUDUSD 역추세숏·AUD/GBP 추세롱)은 마진이 얇아 슬리피지에 민감.
2. **fee 0.11% 가정 검증 필수.** 백테스트는 왕복 0.11% 고정인데, 환율 실비용 = **HFM 실스프레드**. 메이저 스프레드가 0.11%보다 크면(특히 변동성 시간대·롤오버) 위 엣지가 잠식됨. **HFM 실측 스프레드로 재계산** 후 마진 얇은 픽은 컷.
3. **표본 얕음 + 고PF 과적합.** n 80~130(27~44/년). **USDCHF 추세숏 PF6.54·EURUSD 추세롱 PF5.36은 소수 대박 의존 의심** → 그대로 믿지 말고 OOS(워크포워드) 먼저.
4. **상관 주의(중복 노출).** USDCHF ≈ −EURUSD, NZDUSD ≈ AUDUSD, USDCAD ↔ WTI(이미 보유). 동시 진입 시 명목만 부풀고 분산은 안 됨 → 사이징에서 묶어서 한도 관리.
5. **데이터 소스 = Dukascopy(bid).** HFM과 레벨/스프레드 다름. 라이브 z 계산은 HFM 피드로 동일 규칙(win=10080) 재산출.
6. **전부 in-sample(2023-06~2026-06, 강세장 편향).** 약세·고금리 전환 국면 미검증.

## 4. 제외/경계 (참고 — 트레이딩 금지)

- **경계(0~+0.20%, 사실상 본전 → 제외):** 역추세롱 USDCAD(+0.03)·USDJPY(+0.01) / 역추세숏 GBPUSD(+0.01) / 추세숏 USDCAD(+0.09)·GBPUSD(+0.03).
- **음수(엣지 없음):** 역추세롱 USDCHF / 역추세숏 EURUSD / 추세숏 EURUSD·NZDUSD·AUDUSD / 추세롱 USDCAD·USDJPY·USDCHF·NZDUSD.
- → **EURUSD는 추세롱 1개만, USDCAD는 역추세숏 1개만** 유효. 잔잔한 페어는 역추세 거의 안 됨.
